# Changelog

All notable changes to this project are documented in this file.
The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project uses [Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-11-15

First public release.

### Added

- Dockable Markdown preview panel based on Microsoft Edge WebView2.
- GitHub Flavored Markdown rendering with incremental updates on a background thread.
- Code highlighting with copy buttons, KaTeX math, alerts, footnotes, task lists, front matter.
- Two-way scroll sync, click-to-source, table of contents, find in preview, zoom.
- Export to HTML, PDF and Word (DOCX).
- Settings page, automatic opening for Markdown files, light, dark and editor-matched themes.
- Builds for x64, x86 and ARM64.
